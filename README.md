# WM xSchool — Landing Page

A modern, responsive landing page developed with **Next.js** and **TypeScript**, based on the provided Figma design. The project represents the xSchool learning platform and features dynamic content fetched from an external API.

## 🚀 Features

- Pixel-perfect UI implementation based on Figma design
- Fully responsive layout for desktop and mobile devices
- Server-side data fetching using Next.js
- Dynamic content integration with REST API
- Interactive About xSchool image slider
- Animated text marquee section
- Functional FAQ accordion
- Reusable and component-based architecture
- Optimized page rendering with Next.js

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- CSS
- Swiper.js
- REST API
- Git & GitHub


## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd xschool-nextjs
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🌐 API Integration

Project data is fetched from the following API using server-side requests:

```text
https://admin.wemark.pro/api/tasks-xschool/
```

The API provides dynamic content for:

- Banner
- About xSchool
- Founder
- Programs
- Text Slider (Marquee)
- FAQ
